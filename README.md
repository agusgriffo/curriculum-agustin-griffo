# Descripción del proyecto

Este es el primer trabajo práctico para la asignatura Computación II. El objetivo de este currículum vitae digital es poner en práctica y consolidar los conocimientos vistos en clase, utilizando HTML5, CSS3 y Flexbox.

## El proyecto está dividido en las siguientes secciones

**HEADER:** Encabezado principal del currículum, con el nombre y la información de presentación.

**NAV:** Conformado por botones de navegación directa a cada sección importante de la página.

**MAIN:** Contiene la información principal del currículum, organizada en las siguientes secciones:

- **Sobre mí:** Breve presentación personal.
- **Experiencia laboral:** Información sobre mi experiencia previa como diseñador freelance y mi trabajo en la imprenta A5.
- **Estudios:** Información sobre mi formación académica.
- **Habilidades:** Capacidades y conocimientos relacionados con el diseño y la comunicación visual.
- **Herramientas:** Programas y recursos utilizados para el desarrollo de trabajos de diseño.

**FOOTER:** Pie de página con enlaces directos a mis redes sociales y medios de contacto.

## Información técnica

**Editor de código:** Visual Studio Code

**Tamaño de pantalla:** 1920 × 1080

**Tecnologías utilizadas:** HTML5 y CSS

**Maquetación:** Flexbox
